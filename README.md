# Emotion RPG Life Manager

React + Node.js + Oracle DB 기반 감정 기록 및 할 일 관리 웹 애플리케이션입니다.

## 프로젝트 소개
Emotion RPG Life Manager는 사용자의 감정 상태와 일상 할 일을 함께 기록하고 관리할 수 있는 웹 애플리케이션입니다.

사용자는 Todo를 관리하고 감정 일기를 작성할 수 있으며, 감정 데이터를 그래프로 확인할 수 있습니다.

## 주요 기능

### 1. Todo 관리
- 할 일 추가
- 할 일 완료 체크
- 날짜별 할 일 조회

### 2. 감정 일기
- 감정 기록 작성
- 감정 데이터 저장
- 감정 통계 그래프 확인

### 3. 데이터 시각화
- 감정 통계 Pie Chart
- 캘린더 기반 기록 확인

## 기술 스택

- Recharts

Backend

Database
